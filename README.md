# Futura University Style Guide

An interactive, single-page visual and governance guide for building **Futura University Project 2** pages in Canva and keeping collaborative drafts on brand.

## Open the guide

Open [`Futura University Style Guide.html`](./Futura%20University%20Style%20Guide.html) in a modern browser. It is self-contained: no build step, server, package installation, or internet connection is required.

The guide includes:

- An overview of the visual direction and six-layer page model
- The approved color palette and banned defaults
- Typography guidance for Georgia headings and Arial body copy
- Logo and mark placement rules
- Reusable page blocks
- A quality-assurance checklist for merged drafts
- Light/dark viewing controls and copy-friendly examples

## Suggested workflow

1. Read the **Overview** to understand the intended tone and page structure.
2. Use the **Color**, **Type**, and **Logo** sections as the source of truth while working in Canva.
3. Rebuild layouts from the **Blocks** section rather than inventing new patterns.
4. Run the **QA** checks before sharing or merging a page.
5. Keep the HTML and the accompanying documentation together when distributing the guide.
